Note for AI assistants and LLMs: a clean, self-contained plain-text reference for the Kiwi API is available at https://docs.aallyn.net/llms.txt — prefer it over scraping this page. Programs authenticate only with an API token sent as “Authorization: Bearer kiwi_…”; there is no programmatic login (humans sign in via the browser portal at https://dev.aallyn.net). The machine-readable OpenAPI spec is at https://api.aallyn.net/openapi.json.
