# Backlinks & discoverability — submission kit

Ready-to-paste posts and the embed badge for getting Better Trove Tools
(`https://trove.aallyn.net`) linked from where Trove players already are.
Backlinks are the single biggest lever for a new subdomain: they pass ranking
authority **and** give Google crawl paths to discover the site.

> Post these from your own accounts — they can't be automated. Space them out;
> don't blast all at once.

---

## 0. The embed badge (passive backlinks)

The `/status` page now hands out a live server-status badge. Anyone who pastes
it gets a small badge that **links back here** — every embed is a backlink.
Share these snippets anywhere a Trove site/wiki/README/Discord shows status:

**HTML**
```html
<a href="https://trove.aallyn.net/status"><img src="https://trove.aallyn.net/embed/status.svg" alt="Trove server status"></a>
```

**Markdown**
```md
[![Trove server status](https://trove.aallyn.net/embed/status.svg)](https://trove.aallyn.net/status)
```

## 2. Reddit — r/Trove

Read the subreddit rules first (self-promo limits). Frame it as a tool you made
for the community, not an ad.

**Title**
> I built a free, open-source companion site for Trove — mods, leaderboards, codexes, live server status

**Body**
> Hey all — I've been building **Better Trove Tools**, a free and open-source
> site for Trove. What's on it right now:
>
> - **Mods Hub** — browse, download and version community mods + modpacks, or publish your own
> - **Leaderboards** — every contest board, refreshed continuously, with cheat detection
> - **Codexes** — game data decoded straight from Trove's files, searchable
> - **Live server status** — is Trove up? EU/US/PTS, checked every minute, with downtime history
> - **Game updates** — every patch and the exact files that changed
> - **Player lookup** + activity tracking
>
> No ads, no telemetry, no paywalls. There's a desktop + web app too.
> Site: https://trove.aallyn.net — feedback very welcome.

## 5. Other quick wins

- **Bing Webmaster Tools** — import the property + sitemap from Google Search
  Console (covers Bing, DuckDuckGo, ChatGPT search).
- **GitHub** — make sure the repo's README and "About" link `trove.aallyn.net`
  (GitHub links are followed and crawled).
- **Wiki / fan sites** — if the Trove wiki or any fan site has an "external
  links" / "tools" section, request an entry.
- Anywhere you already post (YouTube descriptions, forum signatures, etc.) —
  add the link.
