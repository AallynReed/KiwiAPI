Two bonuses can both say "+30% Critical Damage" and be worth 30 points or 900. Every number on your character sheet is a base value plus a stack of bonuses from your class, gear, gems, allies and buffs, and the game always combines them in the same order. Knowing that order tells you which bonuses are really worth chasing.

The seven kinds of modifier

Every bonus in the game is one of seven types. The game file says which, so a bonus's type never depends on how its number is written.

A Cancel is not a zero

Every modifier carries a name tag set by the designers. A Cancel only switches off modifiers whose stat and tag both match its own; the rest of the stat is untouched. To take a stat away completely, the game multiplies it by 0 instead. That is how Boomeranger, Dino Tamer and Revenant have no Energy, and how Dracolyte and Tomb Raiser have no Attack Speed. Lunar Lancer and Solarion have their Energy Regen fixed at 0 instead.

The order the game uses

Each stat is rebuilt from scratch whenever anything touching it changes, in these steps:

  1. Drop what doesn't apply. Modifiers meant for another game mode, and any modifier a Cancel matches, are left out.
  2. Flat bonuses. Start from the base value and add every flat bonus.
  3. Multipliers and percent bonuses. Multiply by every multiplier, then by 1 + the sum of all percent bonuses.
  4. Floor, then cap. Raise the result to the highest floor, then lower it to the lowest cap. If the two clash, the cap wins.
  5. Fixed values. If the stat has any fixed value, it becomes the lowest one. Steps 2 to 4 are thrown away.
  6. Conversions. A few effects rewrite a stat directly at this point.
  7. Late modifiers. Modifiers flagged to apply late run steps 2 to 4 again on top of the result, with the same floor and cap. They still count after a fixed value.
value = (base + flat bonuses) × multipliers × (1 + percent bonuses)
value = cap(floor(value))
value = lowest fixed value, if there is one
value = cap(floor((value + late flat) × late multipliers × (1 + late percent)))

Every step is held between −1,000,000,000 and 1,000,000,000.

    What it means for your build

    Same "+30%", two different bonuses

    Critical Damage and Attack Speed show as percentages whether a bonus is flat or percent, so the text can't tell you which you have. On a character with 3,000% Critical Damage:

    AllyBonus typeResult
    Hopflite AssassinFlat: +303,030%
    Bulbous HeckmantisPercent: +30% of the stat3,900%

    Better Trove Tools labels the percent kind as a "Bonus" stat, like Critical Damage Bonus, so you can tell them apart on the Allies page.

    Flat bonuses get boosted

    Flat bonuses go in before any multiplier or percent bonus, so every flat point you add is also raised by all of your percentages and your class multiplier.

    Percent bonuses add, multipliers compound

    Each extra percent bonus adds to the same pool, so it's worth a little less than the one before: going from +60% to +90% raises the stat by less than going from +30% to +60% did. Multipliers stack on each other, so each one is worth its full amount.

    Equip order doesn't matter

    Within a type, everything is summed or multiplied together, so the order you put gear on changes nothing.

    A fixed value ignores your gear

    When something fixes a stat, none of your ordinary bonuses on that stat count until it wears off. A missing class stat is the same story: once it's multiplied by 0, no ordinary bonus brings it back.

    Delve modifiers grow fast

    Some delve modifiers scale with how deep you are. Their value is multiplied by (depth × a per-modifier factor)², so going twice as deep makes them four times as strong. See Delve Modifiers for what each one does.

    Game modes

    Every modifier is marked with the modes it works in. Most are marked for both adventuring and PvP; others only count in delves, only in PvP, or everywhere except PvP. A modifier applies when it shares a mode with what you're doing. The stats marked "every mode" in the table above skip this check and always count.

    PvP then converts your stats through its own curves: see How PvP Stats Work. The PvP calculator shows what your sheet becomes in each mode.

    Where this comes from

    Everything here was read out of the Trove game client (the 22 September 2026 build) and checked against the game files, not worked out from testing. The server decides what really happens in a fight, and it almost certainly uses the same rules, but that side can't be checked from the client.
