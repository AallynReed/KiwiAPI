Class player share

Share of players on each class in the latest leaderboard snapshot.

    How this works: each class is measured by its Effort leaderboard (the related Paragon board is left out - its scores are ambiguous). For the time chart, a player counts toward a class when their Effort score rose (or they first appear) between two consecutive captures; the share donut instead counts everyone present on the class's Effort board in the latest capture. The default "Established" view keeps only players who clear both a Power Rank and an Effort threshold on that class - filtering out brand-new characters and throwaway alts; the "All" view counts everyone. Effort resets weekly (Monday 11:00 UTC), so the chart's lines break across the reset rather than dropping to a false zero. Each line shows the class's share of activity over time (hover for the underlying player count); the donut shows each class's share of players in the latest snapshot. "Share" counts a player who plays several classes in each, so the slices sum to 100% but aren't distinct players. It's a lower bound: anyone outside a board's top ranks isn't seen.
