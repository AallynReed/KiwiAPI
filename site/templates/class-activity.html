Class player share

Share of class activity in the most recent capture window.

    How this works: each class has an Effort and a Paragon leaderboard. A player counts as active on a class when their score rose (or they first appear) on either of those boards between two consecutive captures. Both boards reset weekly (Monday 11:00 UTC), so the lines break across the reset rather than dropping to a false zero. The chart plots the average per-hour estimate per class inside each time bucket. "Share" is share of class activity - a player who plays several classes counts in each, so the slices sum to 100% but aren't distinct players. It's a lower bound: anyone outside a board's top ranks isn't seen.
