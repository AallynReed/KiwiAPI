Unlock Debug

Trove has a debug console built into it that the retail client keeps switched off. Pick your game executable and you get the same file back with the console turned on.

Read this first

  • Trove runs anti-cheat. This changes the game's executable, and changing it can get your account banned. Nobody but you can make that call.
  • Keep a copy of the original Trove.exe somewhere safe before you replace it.
  • Close the game completely first - Windows won't let you overwrite a running executable.
  • Every game patch replaces the executable, so you'll need to do this again after one.

Choose your game executable

It's called Trove.exe and lives in your Trove install folder, under Games/Trove/Live.

{# The label wraps the input, so clicking the zone, tabbing to it and pressing Enter, or dropping a file on it all reach the same picker. #}

Your file is patched and handed straight back. It isn't saved, and no account is needed.

Once you've replaced the file

Start the game and press the backtick key (`, above Tab) to open the console. It's the same console the developers use, so it will happily accept a command that breaks your client - close and reopen the game if something goes wrong.
