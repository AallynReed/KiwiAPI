Daily play

Open the app. Get your bearings. Head out.

Daily & weekly buffs, merchant tracking, community streams, and event countdowns — all on one live dashboard that already knows what's running right now.

  • Live daily & weekly buff rotation
  • Corruxion / Fluxion / Stampy countdowns
  • Chaos Chest + Hourly Challenge tracker
  • Trovesaurus stream & news embed

Gems & builds

Crunch thousands of gem combinations.

Tell the optimizer what you've got. Get back the highest-DPS, highest-PR, or highest-Light layout — per class, per light level, with active buffs accounted for.

  • Per-class gem build optimizer
  • Gem Evaluator: keep, reroll, or scrap
  • Free sandbox simulator with drag-and-drop
  • Interactive zoomable Star Chart with shareable build codes

Calculators

Every stat. Every source. No more spreadsheets.

Power Rank, Mastery, Light, Magic Find — each calculator shows you the per-source breakdown so you know why the number changed, not just what it is.

  • Power Rank: gear / dragons / gems / mastery
  • Mastery: PR + Light + MF at every rank
  • Magic Find: Patron, dragons, weekly buffs, chart
  • Light: total from gear, gems, mastery

Codexes

Decoded live from your installed game.

Eight searchable, filterable catalogs — allies, mounts, dragons, mementos, recipes, items, fish, badges — each pulled fresh from the .tfi archives the moment you point BTT at your install.

  • Filter by stat, ability, mastery, designer, category
  • Source context — biome, boss, creature origin
  • Recipe trees with ingredient counts
  • No upstream scraping; data is yours

Modder tools

Loose files in. A shippable .tmod out.

Auto-structure your assets, hot-test in-game with one click, recompile with clean title-based naming. Build, extract, edit, and version-manage .tmods without ever leaving the app.

  • One-click in-game test
  • Extract + edit any .tmod, your own or others
  • Persistent versioned project workspaces
  • Game File Explorer: search/extract .tfi/.tfa

More inside

Everything else at a glance.

Smaller tools, polish, language support — the parts that don't need their own spotlight but still matter every session.

Server Time

Live server clock with world clocks and a Discord-timestamp converter — paste the result straight into chat.

Trovesaurus Browser

Built-in mod store. Search, filter, install, update — no browser tab needed.

Mod Manager

Enable, disable, update, delete — per installation, with conflict detection.

Update Tracker

Snapshot the game, diff every patch — auto-extracted, summarized, with blueprint previews so you can see what actually changed.

Gem Evaluator

Rate any gem before you sink flux into it.

Mastery Calc

Plan Trove + Geode mastery — PR / Light / MF at every rank.

Blueprint Editor

Open .qb / .blueprint, inspect voxels in 3D, export. Experimental.

Project Manager

Persistent versioned mod workspaces — organized, always ready.

Settings & FPS unlock

Theme, 9 languages, install management — plus an FPS cap that goes from 60 all the way to uncapped, with automatic backups so you can roll back any time.
