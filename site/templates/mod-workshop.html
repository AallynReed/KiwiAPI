Mod Workshop

Turn your files into a mod Trove can actually load, or open a mod back up to see what's inside it. Every file is checked against the game first, so nothing ends up somewhere the game will never look.

1

Add your files

A whole mod folder, a handful of loose files, or a mod someone zipped up. You can also open a finished mod here to fix it and build it again.

Drop your files here

Nothing is saved. Your files are checked, packed and handed straight back.

2

Check where everything lands

Trove only replaces a file if your copy sits exactly where the game keeps the original. Anything the game recognises can be put in the right place for you.

3

Name it and download

The name is what Trove shows in your mods list, so give it something you'll recognise.

Settings file

This mod has an interface that can be configured. Pick the settings file to pack with it.

Drop the file into Trove's mods folder and restart the game.

1

Open a mod

See who made it, what's packed inside, and whether the game will actually read any of it. Save the whole thing as a folder, or pull out a single file.

Drop a mod file here

Nothing is saved. The mod is opened, described and forgotten.

2

What's inside

Built with the same tools the Mods Hub uses, so a mod made here is the same as one released there. Browse the Mods Hub
