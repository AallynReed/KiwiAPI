Mod Workshop

Turn your files into a mod Trove can actually load, or open a mod back up to see what's inside it. Every file is checked against the game first, so nothing ends up somewhere the game will never look.

Add your files

A whole mod folder or a handful of loose files. You can also open a finished mod here to fix it and build it again.

Drop your files here

Pick the zip

Mods get passed around as zips, and Trove can't read one. Drop it here and it comes back as a file the game will load — with every file checked against the game on the way.

Drop a zip here

Check where everything lands

Trove only replaces a file if your copy sits exactly where the game keeps the original. Anything the game recognises can be put in the right place for you.
